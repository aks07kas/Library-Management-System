# Library Management System

A Java + MySQL based project designed to manage books, students, and issue/return records. It demonstrates JDBC connectivity, CRUD operations, and relational database concepts.

## 🚀 Features

* Add, update, delete book records
* Register student details
* Issue and return books
* Maintain transaction history
* View all available books
* MySQL database integration

## 🛠️ Technologies Used

* Java
* JDBC
* MySQL
* SQL Queries
* IDE: VS Code / Eclipse

## 🗄️ Database Structure

Tables:

* **books**
* **students**
* **issue_records**
